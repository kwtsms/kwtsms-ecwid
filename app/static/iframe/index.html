Help
Getting Started +
  1. Go to the Gateway tab and enter your kwtSMS credentials.
  2. Click Login / Verify to connect your account.
  3. Select your Sender ID from the dropdown and save.
  4. Go to Templates and customize your SMS messages.
  5. Go to Integrations and enable the events you want.
  6. Toggle the plugin ON in the General tab.
  7. Send a test SMS from the Gateway tab to verify delivery.

Troubleshooting +
SMS not sending
Check credentials in Gateway tab. Verify plugin is enabled in General tab. Check your kwtSMS balance.
Test mode active
Disable Test Mode in General tab for live delivery. In test mode, messages are queued but not delivered.
Wrong phone format
Use international format without +: 96598765432. The plugin auto-converts common formats.
Balance not updating
Balance syncs daily at 03:00. Click Refresh in Gateway tab for immediate update.
Arabic text garbled
Make sure you selected the Arabic (AR) template and saved it. Arabic uses Unicode encoding (70 chars/page).
