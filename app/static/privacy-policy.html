Privacy Policy

Last updated: March 2026

This Privacy Policy describes how kwtSMS for Ecwid ("the App", "we", "us") collects, uses, and stores data when installed on an Ecwid store.

1. Data We Collect

  • Ecwid Store ID: Your store identifier, received during app installation via the Ecwid iframe payload. Used to make API requests to your store.
  • Ecwid Access Token: An OAuth access token granted during installation. Stored encrypted at rest using AES-256 (Fernet). Used to fetch order details from the Ecwid REST API.
  • kwtSMS API Credentials: Username and password for your kwtSMS account, entered manually in the app settings. Stored encrypted at rest using AES-256 (Fernet). Never transmitted to any party other than kwtsms.com.
  • Customer Phone Numbers: Order phone numbers fetched from Ecwid when a webhook event fires. Used to send the SMS notification. Stored in the SMS log for audit purposes with partial masking (e.g., 9659***5432).
  • SMS Message Content: The rendered SMS body sent to each customer. Stored in the SMS log for audit purposes.
  • Order Data: Order ID, total, status, customer name, and tracking number fetched from the Ecwid API to render SMS templates. Not stored permanently; used only to compose the SMS message.
  • Admin Phone Numbers: Optional list of phone numbers to receive admin copies of SMS notifications. Entered manually by the merchant.

2. How We Use Your Data

  • To send automated SMS notifications to customers for order events (new order, payment update, fulfillment update).
  • To display your account balance and sender IDs in the app settings.
  • To maintain an SMS delivery log visible only to the merchant in the app settings.

3. Data Storage and Security

  • All data is stored in a SQLite database on the server where the app is hosted. The merchant controls this server.
  • Sensitive credentials (Ecwid access token, kwtSMS username and password) are encrypted at rest using AES-256 symmetric encryption before being written to the database.
  • No credentials are transmitted in plain text. All API calls use HTTPS.
  • No credentials or personal data are ever included in client-side JavaScript or HTML source.

4. Data Sharing

We share data only as strictly required to deliver the service:

  • kwtsms.com: Customer phone numbers and SMS message content are transmitted to the kwtSMS API to send SMS notifications. kwtSMS is subject to their own privacy policy.
  • Ecwid (Lightspeed): The app fetches order data from the Ecwid REST API. No data is written back to Ecwid by this app.
  • No data is sold, shared with advertisers, or transmitted to any other third party.

5. Data Retention

  • SMS logs are retained until the merchant manually clears them via the app settings (Logs tab > Clear Logs).
  • Credentials and settings are retained until the app is uninstalled from the Ecwid store.
  • Upon uninstallation, all stored credentials (Ecwid access token, kwtSMS credentials) are permanently deleted from the database. SMS logs are also deleted.

6. GDPR Compliance

If you are subject to the General Data Protection Regulation (GDPR), the following applies:

  • Data Controller: The merchant operating the Ecwid store is the data controller for customer phone numbers processed by this app.
  • Data Processor: kwtSMS for Ecwid acts as a data processor on behalf of the merchant.
  • Right to Erasure: Merchants can delete all SMS logs at any time via the app settings. Uninstalling the app removes all stored data.
  • Data Minimization: Only the minimum data required to send SMS notifications is collected and stored.

7. Children's Privacy

This app is intended for use by business merchants only. We do not knowingly collect data from individuals under the age of 18.

8. Changes to This Policy

We may update this Privacy Policy from time to time. The "Last updated" date at the top of this page reflects the most recent revision. Continued use of the app after changes constitutes acceptance of the updated policy.

9. Contact

For privacy questions or data deletion requests, contact us at: kwtsms.com/support
